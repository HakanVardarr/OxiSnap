v0.1.0-alpha OxiSnap

A blazing-fast, memory-safe screenshot extraction and sharing tool built entirely in Rust — hooking directly into native OS APIs with zero overhead and absolute safety guarantees.

Rust · stable Swift 5.9+ MIT License
Overview

GPU-direct pixel capture

OxiSnap bypasses traditional high-overhead screenshot utilities and hooks directly into Apple's ScreenCaptureKit to extract raw pixel buffers directly from the GPU. Zero copy. Zero latency. Absolute memory safety.

The project is structured as a modular Cargo workspace — separating the core capture engine, the CLI frontend, and the upcoming networking backend for rapid peer-to-peer sharing.

Core Technologies

What it's built on

⬡
Rust (stable)
Memory safety without a GC. The entire engine is Rust, providing the robust workspace architecture.
⇄
swift-rs
Zero-cost Swift–Rust interop bridge, handling ARC automatically and preventing memory leaks.
◉
ScreenCaptureKit
Apple's modern C/Swift API for high-performance display stream capture on macOS.
▦
image (crate)
Fast raw-byte-to-PNG encoding and BGRA→RGBA pixel channel manipulation.
Architecture

Workspace structure

Three highly decoupled crates — each with a single responsibility — ensuring scalability and cross-platform ease.

oxisnap/ workspace
./capturer-core/
The engine. OS-specific FFI implementations and safe Rust traits. All unsafe code is strictly encapsulated behind the ScreenCapturer trait.
./capturer-cli/
The frontend. A lightweight terminal interface for capturing. Built on top of capturer-core, zero OS coupling.
./backend/
The network layer. Future P2P and HTTP sharing logic. Kept separate so the capture engine never takes a network dependency.

Getting Started

Build from source

OxiSnap uses a custom build.rs that auto-detects your host OS, compiles the native Swift/C libraries, and links all required RPATH entries.

Prerequisites: Rust (stable) · Xcode CLT · Swift 5.9+
bash build & run 
# Clone the repository
git clone https://github.com/yourusername/oxisnap.git
cd oxisnap

# Build and run the CLI application
cargo run -p capturer-cli --release
